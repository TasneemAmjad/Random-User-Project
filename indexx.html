Project Description

This project builds a Random User Generator App that:

  • Saves favorites
  • Includes a mini game
    • It’s basically a real-world frontend dashboard simulation.

    Importance of the Project

    Understanding APIs and dynamic UI updates is crucial in web development. This project builds practical skills used in real-world applications such as dashboards, social media apps, and data-driven platforms.
